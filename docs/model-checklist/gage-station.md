**Station:** GAGE · generated 2026-10-18

**Scope:** Phase 3 - the tracked part flow along the line (src/sim), the demo operator actor and the manual GO/NO-GO gage station (EQ-007). EDUCATIONAL trend model only: the heat index and the GO/NO-GO dimensions are illustrative, and the gage station is an unverified concept. This is not the plant program and not a verified gage.

The OPD/spline gage station (EQ-007) was deferred at Phase 2b increment 5 because NO photograph shows it (NV-016) and the only size figures in the source are given as an example, not a program table (NV-014). Phase 3 therefore models the gage as a CONCEPT on the unverified 'conceptual' layer: a bench, a labelled GO master and NO-GO master, a probe and a result flag - enough to show the *principle* of a manual go / no-go size check, clearly placarded 'GAGE (ASSUMED) / NV-016'. No gage brand, no pin diameters, no part tolerances and no check sheet are claimed. The human operator is a generic demo actor (hi-vis, hard hat): it is not plant staff, no PPE spec is claimed and it is not placed from any source. Part positions follow the accepted model x-axis; travel speed, dwell times, spawn interval, heat index and the GO/NO-GO window are all invented to make the flow legible and are labelled illustrative in the code and UI. The sim is deterministic and unit-tested (src/tests/sim.test.ts, 12 tests) so the flow can be reasoned about, but the numbers are not validated against the plant. Human sign-off of the gage concept (GS-16) is outstanding.
